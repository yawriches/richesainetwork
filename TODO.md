## Paid-member community management

- The community is accessible only to authenticated users with a currently active paid membership period, while administrators retain access for moderation; non-members see a clear membership-required state and cannot read or mutate community content through direct API calls.
- Community settings are stored in the database and managed from Admin: enabled state, paid-membership requirement, posts per day, comments per day, post cooldown, maximum active posts, post length, comment length, and image-size limits.
- Community member controls support active, suspended, and banned states, optional posting blocks, moderator reason, and audit history; suspended or banned members cannot post, comment, react, report, or upload community media.
- Server and database enforcement applies post-per-day, comment-per-day, cooldown, and active-post limits; the access response exposes current usage and a safe explanation for the learner paywall.
- Admin Community Control Center supports member search, suspend/unsuspend/ban controls, moderation queue, hide/restore/delete post and comment actions, report resolution, and visible community settings and usage summaries.
- All community moderation changes record an administrator, action, target, reason, and timestamp; community images remain private and signed only for authorized paid members or administrators.

## AI support agent

- The platform provides a public and signed-in learner AI support assistant using the server-side platform LLM service; provider credentials never reach browser code.
- Public answers use only approved published public FAQ, policy, and published-course context. Signed-in answers may add the learner’s own profile, enrollments, progress, review balance, and membership state.
- Course-specific or protected answers require a server-side entitlement check; the assistant must not reveal protected lesson/resource content to a learner without access.
- The assistant stores minimal conversations, messages, selected source IDs, model ID, and timestamps for support quality review, with safe limits and no account mutation capability.
- Admin AI Support control center provides enable/disable, public/learner availability, model, system guidance, welcome/fallback copy, rate limits, source create/edit/publish/archive, and recent conversation review controls.
- The learner/public assistant shows grounded source references, clear unavailable/uncertain responses, and an escalation path to human support.
